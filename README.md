NIGHTVAULT — an original top-down 2D canvas stealth heist. Slip past patrolling guards with visible vision cones, hide behind crates, pillars and display cases that block line of sight, steal the gem and reach the exit unseen across three escalating vaults. Pure HTML/CSS/JS, no dependencies, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — move with WASD / arrow keys, or click anywhere to walk there.
